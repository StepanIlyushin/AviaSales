# AviaSales

Консольная информационно-справочная система для поиска, покупки и управления авиабилетами. 

> Данный проект был разработан самостоятельно в качестве задания по дисциплине "Практикум на ЭВМ" на 1 курсе факультета ПМ-ПУ СПбГУ. Главная техническая особенность реализации - отказ от использования стандартных контейнеров STL (за исключением std::string).

## Функциональность

База данных взаимодействует с пользователем через стандартный ввод/вывод и поддерживает хранение следующих сведений об авиабилетах: 
* номер рейса;
* аэропорт вылета и прибытия;
* дата и время вылета/прилёта;
* количество доступных билетов;
* стоимость.

Для каждой записи автоматически добавляется уникальный номер записи 

## Поддерживаемые команды

* `load имя_файла_с_БД` — чтение базы данных из файла;
* `save имя_файла_с_БД` — запись базы данных в файл;
* `add номер рейса, аэропорт вылета, аэропорт прибытия, дата и время вылета, дата и время прилёта, количество билетов, цена` — добавление авиабилетов;
* `delete ID` — удаление записи по её уникальному номеру ID;
* `clear` — удаление всех записей из базы данных, у которых количество билетов равно 0;
* `print` — вывод всего списка авиабилетов, отсортированного по возрастанию даты и времени вылета, номеру рейса, цены и количества билетов;
* `departure аэропорт_вылета дата_вылета` — список рейсов отправляющихся из заданного аэропорта в определеную дату, отсортированных по времени вылета и номеру рейса;
* `arrival аэропорт_прибытия дата_прилёта` — список рейсов прибывающих в заданный аэропорт в определеную дату, отсортированных по времени прибытия и номеру рейса;
* `schedule аэропорт дата_вылета` — расписание, список рейсов отправляющихся из заданного аэропорта и прибывающих в данный аэропорт в определеную дату, отсортированных по времени и номеру рейса;
* `from аэропорт_вылета to аэропорт_прилёта on дата_вылета` — список билетов (количество больше 0) на текущую дату, отсортированный по возрастанию цены (при равенстве цен упорядоченные по возрастанию времени вылета, номеру рейса и количеству билетов);
* `find аэропорт_вылета to аэропорт_прилёта` — самый дешёвый авиаперелет, возможно с одной пересадкой длительностью не более 24 часа (количество билетов должно быть больше 0);
* `buy номер_рейса дата_вылета` — купить самый дешёвый билет на заданный номер рейса на заданную дату (кол-во билетов в базе должно уменьшиться на единицу);
* `export имя_файла` — вывод всего списка авиабилетов (отсортированного по возрастанию даты и времени вылета, номеру рейса, цены и количества билетов) в текстовый файл;
* `total records` — вывод количества записей в базе;
* `total tickets` — вывод количества билетов в базе;
* `quit` — завершение работы.

Приглашение ко вводу команд (строка, которая отображается слева от каждой команды, которая будет вводиться в терминале) имеет вид `> ` (символ больше и пробел).
